> **Overview:** T.O.N.S Asset Retriever is a dedicated utility designed to resolve user-provided URLs and securely download corresponding public media assets to be used offline in local desktop environments.

---

### Ⅰ. Technical Capabilities

* **URL Resolution:** Parses provided web links to locate and retrieve specific media files.
* **Direct Extraction:** Downloads raw asset files and packages them directly into accessible local directories.
* **Minimalist Interface:** A streamlined graphical user interface focused strictly on network input/output operations.
* **Local Library Management:** Facilitates the creation of an offline repository for desktop media files.

---

### Ⅱ. System Requirements

| Specification | Requirement |
| :--- | :--- |
| **Operating System** | Windows 10 / Windows 11 |
| **Architecture** | x64 |
| **Network** | Active internet connection for URL resolution and downloading |
| **Storage** | Sufficient local space for retrieved media files |

---

### Ⅲ. Usage Instructions

1. Go to the **Releases** page and download the latest executable binary.
2. Extract the files to a directory of your choice.
3. Launch the application.
4. Input the target media URL into the designated field to initiate the retrieval process.
